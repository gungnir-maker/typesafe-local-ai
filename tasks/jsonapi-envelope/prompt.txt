Write `envelope(items, page, size, total)` in envelope.py.

Build the response body for a paginated list endpoint.

Return a dict shaped exactly like this:

    {
      "data": [...],                     # the items for this page
      "meta": {
        "page": 1,                       # int
        "size": 20,                      # int
        "total": 135,                    # int
        "pages": 7                       # int, ceil(total / size)
      },
      "links": {
        "self":  "/items?page=1&size=20",
        "next":  "/items?page=2&size=20",   # null on the last page
        "prev":  null                       # null on the first page
      }
    }

Rules:
- `pages` is `ceil(total / size)`, and is 0 when `total` is 0.
- `next` is null when `page >= pages`.
- `prev` is null when `page <= 1`.
- `size` of 0 or less raises ValueError; so does a negative `total` or a
  `page` below 1.
- `data` is the list passed in, unchanged.

Return the complete new contents of envelope.py.
